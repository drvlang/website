# drvlang.org

This is the public website for [drvlang](https://drvlang.org), generated by [mmdoc](https://github.com/ryantm/mmdoc). Edit the pages in `doc/` and list each page’s anchor in `doc/toc.md`.

Run `nix build` to generate the site in `result/`. Building mmdoc requires the [drvc Nix settings](https://github.com/drvlang/drvc#try-it-with-mmdoc). A push to `main` builds that same flake and deploys the static output to GitHub Pages. The custom domain is configured on the repository’s Pages settings and in Cloudflare DNS.
